
# Data Storytelling Dashboard - README

## PROJECT OVERVIEW

This project is a Streamlit based data storytelling dashboard built using the Zomato dataset. It provides insights into restaurant trends, ratings, costs, locations, and online ordering behavior.

---

## FEATURES

* Dataset preview and cleaning
* Key performance metrics (KPIs)
* Restaurant type analysis
* Rating distribution
* Cost analysis
* Location insights
* Online order and table booking analysis
* Business insights and recommendations

---

## TECHNOLOGIES USED

* Python
* Pandas
* Plotly
* Streamlit
* Pyngrok

---

## DATASET

The dataset includes restaurant details such as name, location, rating, cost for two people, restaurant type, online order availability, and table booking availability.

---

## HOW TO RUN (LOCAL)

1. Install requirements:

```text id="w1"
pip install streamlit pandas plotly
```

2. Run the application:

```text id="w2"
streamlit run app.py
```

---

## HOW TO RUN (COLAB)

1. Upload dataset
2. Run Streamlit with ngrok
3. Open generated public URL

---

## INSIGHTS

* Most restaurants are located in major cities
* Mid-range restaurants dominate the market
* Online ordering is widely available
* Ratings mostly range between 3.5 and 4.5
* Table booking is less common

---

## CONCLUSION

This dashboard helps analyze customer behavior and restaurant performance to support better business decisions.
